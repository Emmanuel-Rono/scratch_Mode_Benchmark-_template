# Task Directive — Scratch Mode

## Objective
Create the requested artifact from the agent-visible inputs in `environment/`.

## Inputs
Describe the provided source files/data and any allowed external sources.

## Required deliverable
- Define output file type, name, and location.
- Define mandatory outputs, sections, fields, or machine-readable summary values.
- Define units, schemas, ordering, and citation/provenance requirements.

## Construction freedom
State what the agent may choose freely (layout, formulas, intermediate calculations, file structure) and what is mandatory.

## Evaluation dimensions
Describe the dimensions that will be graded, such as correctness, dependency/provenance, structure, and presentation.

## Tolerances
Document numerical/date/text tolerances explicitly.

## Submission
Save the completed artifact to the output path defined in `task.toml`.

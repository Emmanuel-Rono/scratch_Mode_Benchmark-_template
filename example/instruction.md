# Demo Task — Scratch Mode

Using `environment/inputs/observations.json`, create a new JSON artifact at `/output/submission.json`.

Required fields:
- `title`: a non-empty human-readable title.
- `result.total_items`: count of observations.
- `result.average_score`: arithmetic mean of all scores.
- `result.top_id`: ID of the observation with the highest score.
- `result.source`: a non-empty source reference describing the input used.

You may choose any other fields or ordering. The grader awards partial credit across correctness, provenance, structure, and presentation.
